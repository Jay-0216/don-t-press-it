# DON'T PRESS IT.

A tiny interactive web experiment built around one suspicious red button.

## Prototype goals

- Ivory, almost empty interface
- One large tactile red button
- No tutorial, menus, XP, or visible game systems
- Small unpredictable reactions instead of an event on every click
- Local anonymous memory for repeat visits
- Mobile-friendly long press + vibration
- Browser-level jokes using the page title

## Current prototype limitation

The number shown as `people did.` is **demo/local state**, not yet a real global counter.

The intended next backend step is anonymous identity + a server-authoritative global counter + realtime events.

## Run

Open `index.html` in a browser.
